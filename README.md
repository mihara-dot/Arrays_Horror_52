### Задание
Для заданной целочисленной матрицы H найти минимальную сумму модулей элементов среди всех диагоналей, параллельных побочной диагонали. Вывести исходную матрицу, суммы модулей элементов каждой диагонали и минимальную сумму.

### Ввод данных
С клавиатуры вводятся количество строк и столбцов матрицы, а затем её элементы. Количество строк и столбцов должно находиться в диапазоне от 1 до 20, модуль каждого элемента не должен превышать 1000. При некорректном вводе программа выводит сообщение `INVALID` и завершает работу.

### Запуск программы
Скомпилировать файл `ArraysHorror52.cpp` компилятором C++, запустить полученную программу и ввести размеры матрицы и её элементы по запросу. После вычислений программа выведет исходную матрицу, суммы диагоналей и минимальную сумму.
